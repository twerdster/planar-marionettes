ABOUT THIS IMPLEMENTATION

A photograph, separated
into moving parts.

A pose model locates the joints and a person mask separates the foreground. The cutout is divided into a head, torso and limb segments, then attached to a 2D rig. Video changes the rig’s pose while keeping the reference photograph’s proportions.

Start with a clear, full-body view. Crossed limbs, hidden body parts, loose clothing and turns away from the camera can produce incomplete or incorrectly assigned cutouts. Joint correction helps alignment; it cannot reveal hidden surfaces.

A new browser implementation by Aaron Wetzler, based on Puppify — Automatic Generation of Planar Marionettes from Frontal Images, by Elad Richardson and Gil Ben-Shachar, supervised by Anastasia Dubrovina and Aaron Wetzler. Read the original report ↗
